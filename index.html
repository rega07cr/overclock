La sezione dedicata all'unico obiettivo che conta: GPU MAX (GameDVR off, Game Mode on, cache shader + DirectX + Steam pulite, HAGS, MPO off anti-stutter, TdrDelay anti-freeze, priorità GPU ai giochi, throttling off, PCIe/USB sempre alimentati) + CPU MAX (Ultimate Performance, CPU 100% + core parking OFF + boost aggressivo, foreground boost, scheduler giochi, throttling off) + extra (UI leggera + RAM standby liberata). Niente più freeze alle tue app

Il Freeze Buff è stato rimosso: Game Boost e FPS MOD non sospendono più Discord, browser o musica. Potenziano solo il gioco (priorità High + core dedicati + patch config con backup). Le altre app restano aperte e fluide.

Disco & Junk + 3 livelli

Base: solo file TEMP vecchi di 7+ giorni. Media: tutta la TEMP + cache shader. Potente: + cache Windows Update e miniature. Solo cache rigenerabili: mai documenti, mai giochi.

Rete: DNS + TCP

Svuota la cache DNS per un ping più stabile. A livello Media/Potente ottimizza anche il TCP (autotuning, RSS, ECN) se hai i permessi admin — i valori originali vengono salvati per il ripristino.

Changelog — v1.3.0 stable · cosa cambia dalla v1.2

Hai la v1.2? Ecco le 3 novità della v1.3, spiegate semplice — niente scatole nere, tutto reversibile.

  • 🚀 FPS MAX BEAST — GPU MAX + CPU MAX + extra, solo più FPS.
    Cosa fa: GPU — GameDVR/capture OFF + Game Mode ON, cache shader NVIDIA/AMD + DirectX + Steam pulite (via gli scattini), HAGS, MPO off (niente stutter a 144 Hz+), TdrDelay=8 (il driver non resetta più la GPU nei picchi = niente freeze di 2 s), priorità GPU ai giochi, throttling off, PCIe/USB sempre alimentati. CPU — piano Ultimate Performance (o Prestazioni elevate), CPU sempre al 100%, raffreddamento ATTIVO, core parking OFF (tutti i core svegli), boost aggressivo, foreground boost. Extra — UI leggera (trasparenza/animazioni off) + RAM standby liberata subito.
    Cosa NON tocca: driver, giochi, salvataggi, Discord/browser/musica (restano fluidi). Come si annulla: ↩ Ripristina FPS MAX (snapshot dedicati, vale anche dopo il riavvio). Onesto: nessun software fa ×100 — qui spremi il massimo via software.
  • 🎮 Lancia gioco ottimizzato — nuova card in FPS MAX.
    Cosa fa: avvii il gioco dall'app: applichiamo mod FPS temporanee (patch config con backup .ocbak) + argomenti di lancio ufficiali per-gioco (es. CS2 -high -novid +fps_max 400) + priorità High, anche via steam://rungameid/. Quando chiudi il gioco ripristiniamo tutto da soli.
    Cosa NON tocca: se avvii il gioco da fuori, niente mod. Come si annulla: ■ Stop / Ripristina, o chiudi il gioco — torna tutto come prima.
  • 🌀 Sezione Ventole — rumore vs raffreddamento, a tua scelta.
    Cosa fa: profili Silenziosa (policy passiva + CPU 85%: poche ventole, qualche FPS in meno) / Bilanciata (default Windows) / Massima (policy attiva + boost: CPU mai throttlata, più rumore) + % manuale 10–100% + stato in sola lettura (temperatura, policy, vendor) + reset automatico che rimette la modalità di fabbrica. Onesto: Windows non ha un'API standard per i giri — la policy Windows si applica sempre, per i giri esatti proviamo le interfacce WMI del produttore o ti diciamo quale app ufficiale usare (Legion Zone, Armoury Crate…): niente driver strani.
    Cosa NON tocca: curve custom esistenti (le ritrovi col reset), BIOS. Come si annulla: ↩ Reset automatico (snapshot dedicato).
  • ⬅️ v1.2.0: disinstallazione semplice, salute sistema, reset totale vero.

FAQ & Privacy

Funziona davvero 100% offline?

Sì. Il modulo AI usa Ollama (http://localhost:11434) con modelli come Llama 3 / CodeLlama / Mistral. Nessun byte di codice lascia il tuo PC se scegli la modalità offline. I provider cloud sono opt-in.

Quali dati raccogliete?

Nessuno. Niente telemetria obbligatoria, niente account. Le statistiche di sistema restano in locale.

Come faccio a usare Ollama?

Installa Ollama, poi ollama pull llama3 && ollama pull codellama. Overclock lo rileva da solo e mostra ● OLLAMA ONLINE nelle Settings.

È sicuro il Game Boost?

Sì: alza priorità e affinità solo mentre giochi e ripristina tutto all'uscita. Su Linux usa i tuoi Proton/Gamemode esistenti, non li sostituisce.

Su quali OS gira?

Windows 10/11 (.exe/.msi/portable), macOS Universal (.dmg), Linux (.AppImage/.deb/.tar.gz).
